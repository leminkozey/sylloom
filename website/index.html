Install Sylloom
git clone https://github.com/leminkozey/sylloom.git
cd sylloom
./install.sh
sylloom

The installer sets up the CLI and downloads the local models.

What you’ll need +

Apple Silicon Mac. macOS 14.4 or later. Homebrew installed. About 10 GiB free for the default models; 16 GiB RAM recommended.

macOS will ask for recording permissions. Accessibility access enables insertion into other apps.
